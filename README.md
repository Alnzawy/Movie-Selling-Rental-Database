# Movie Selling and Rental Company (MSRC)

## Overview
A collaborative academic database project developed as part of the CIS 3300 – Database Systems course at the Islamic University of Madinah during the first semester of the 2023–2024 academic year.

The project focuses on designing and implementing a relational database system for a movie selling and rental company. The system manages movie information, actors, genres, customers, sales, and rental transactions.

## Project Objectives
- Design a conceptual database schema using the Entity-Relationship (ER) model.
- Map the ER model into a relational database model.
- Implement the relational schema using MySQL.
- Develop and execute SQL queries to retrieve and manage data.

## Core Database Entities
- **Movie:** Stores movie details such as title, release year, rating, box office, duration, director, and awards.
- **Actor:** Stores actor information and personal details.
- **Genre:** Classifies movies into categories such as Action and Comedy.
- **Customer:** Stores customer information.
- **Sell:** Manages movie sales transactions.
- **Rent:** Manages movie rental transactions.
- **Relationship Tables:** Handle relationships between database entities.

## Technologies & Tools

- Entity-Relationship (ER) Modeling
- Relational Database Design
