# Movie Selling and Rental Company (MSRC)

## Overview

A collaborative academic database project developed as part of the **CIS 3300 – Database Systems** course at the **Islamic University of Madinah** during the First Semester of the 2023–2024 academic year.

The project focuses on designing and implementing a relational database system for a Movie Selling and Rental Company (MSRC). The system manages movie information, actors, directors, customers, sales, and rental transactions.

## Project Objectives

- Design a conceptual database schema using the Entity-Relationship (ER) model.
- Map the ER model into a relational database model.
- Implement the relational database using MySQL.
- Develop and execute SQL queries to retrieve and manage data.
- Establish relationships between database entities.
